Before you start

Chrome or Edge (desktop) Data USB cable Plugged in directly, no hub No port? install CP210x / CH343 driver

Pick your board, hit Install, and choose the serial port when prompted. Images are built automatically from olosnoks/warhog. Flashing a whole batch? Flash several boards at once →
New here? Read the documentation — how the firmware works and how it differs from upstream Piglet.

How to use the flasher

  1. Plug your board into the computer with a data USB cable — directly, not through a hub.
  2. Pick your board from the dropdown below.
  3. If a Firmware toggle appears (the C5 boards), choose skon’s fork or official.
  4. Click Install and select the serial port when the browser asks.
  5. Let it finish, then unplug and replug (or power-cycle) to boot the new firmware.
  6. No port listed? Install the CP210x / CH343 USB driver and try again.

WarHog Core — XIAO C5

ESP32-C58 MBGPSdual-band

WarHog Core — GPS, SD, WiGLE logging, mesh. Dual-band 5 GHz. Flashes directly via ROM bootloader (--no-stub).

Firmware

Download .bin manifest
Browser flash failing? Terminal fallback

The Install button above flashes the C5 in ROM (--no-stub) mode so the USB-Serial/JTAG link doesn’t drop. If your board doesn’t enter download mode automatically, hold BOOT, tap RESET, release BOOT, then click Install — or flash from a terminal:

# one-time: esptool v5+ supports C5
pip install -U esptool
# flash the merged .bin at offset 0 with --no-stub:
esptool --chip esp32c5 --no-stub write-flash 0x0 xiao_c5.bin
